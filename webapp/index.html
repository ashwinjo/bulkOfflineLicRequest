Start the page

From this project folder, with Python 3.11 or newer. The first three lines are needed once.

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python webapp/server.py

Open 127.0.0.1 on port 8765. The server prints that address when it starts.

Self-host

Run the server on a machine that can reach the chassis. It binds to 127.0.0.1 and port 8765, so only that machine can open the page. Fonts, the script, and the styles are files in webapp/. Chassis calls do not use a proxy, and certificate checks stay off.

To let another machine on your network open it, pass a bind address. Passwords are typed into this page, so keep the default unless you mean to share it.

python webapp/server.py --host 0.0.0.0 --port 8765

crews.txt

One chassis on each line: ip, username, password. Copy crews.example.txt and edit it. The file holds passwords and is not committed.

<ip>,<username>,<password>
10.0.0.1,admin,changeme
10.0.0.2,admin,hash#1,extra

The password is everything after the second comma, so it may contain commas. A first line whose first field is ip or <ip> is a header and is skipped, as are blank lines and lines that start with #. An address may be a hostname or an IPv4 address, with an optional port such as 10.0.0.1:8443. A repeated address keeps the first line.

The command line

The same work, without this page. --input reads crews.txt unless you pass another file.

python bulk_offline_lic.py --input crews.txt --output out
python bulk_offline_lic.py install --license /path/to/licenses --input crews.txt
